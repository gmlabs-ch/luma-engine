# Scenes (`.scene`) and entities (`.entity`)

A *scene* is a room of the game: a stack of **layers**, each holding
**entities** (sprites placed in the scene: the background, props, doors)
and **regions** (polygons: the walkable floor, blocked areas, zones that
scale or tint whoever stands in them), plus **waypoints** for path finding,
**scale levels** and **rotation levels** that vary with the position, and a
few scene-wide settings. One layer is the *main layer*; its size is the size
of the scene, and the other layers scroll with parallax relative to it.

Sources: the MIT-licensed [WME Lite](https://github.com/MnemonicWME/wmelite)
sources (`AdScene.cpp`, `AdLayer.cpp`, `AdSceneNode.cpp`, `AdEntity.cpp`,
`AdObject.cpp`, `AdRegion.cpp`, `BRegion.cpp`, `AdScaleLevel.cpp`,
`AdRotLevel.cpp`, `AdWaypointGroup.cpp`, `BScriptHolder.cpp`), the
MIT-licensed Wintermute Engine 1.x sources for the `CAMERA` key, and
analysis of game files.

Implemented by `luma_formats::scene`, and shown by
`luma scene <game> <file>`.

## Example

```
; generated by SceneEdit

SCENE {
  NAME="StoreRoom"
  CAPTION=""
  PERSISTENT_STATE=TRUE
  SCRIPT="scenes\storeroom\scr\scene_init.script"
  SCRIPT="scripts\scene.script"

  WAYPOINTS {
    NAME="new waypoints"
    POINT {547,707}
    POINT {702,662}
  }

  LAYER {
    NAME="main"
    MAIN=TRUE
    WIDTH=1859
    HEIGHT=768
    ACTIVE=TRUE
    ENTITY {
      NAME="background"
      X=0
      Y=0
      SCALABLE=FALSE
      INTERACTIVE=FALSE
      COLORABLE=FALSE
      SPRITE="scenes\storeroom\artwork\backgroundstoreroom.png"
    }
    REGION {
      NAME="floor"
      BLOCKED=FALSE
      DECORATION=FALSE
      ACTIVE=TRUE
      SCALE=0
      ALPHA_COLOR { 255,255,255 }
      ALPHA = 255
      POINT {494,768}
      POINT {641,610}
      POINT {1700,620}
      POINT {1859,768}
    }
    ENTITY {
      NAME="MESConsole"
      CAPTION="/STORER0002/Console"
      X=1184
      Y=230
      SCALABLE=TRUE
      INTERACTIVE=TRUE
      COLORABLE=TRUE
      WALK_TO_X=1195
      WALK_TO_Y=379
      WALK_TO_DIR=0
      CURSOR="interface\cursors\cursorup.sprite"
      SCRIPT="scenes\storeroom\scr\mesconsole.script"
      REGION {
        NAME="<unnamed>"
        ACTIVE=TRUE
        POINT {1150,184}
        POINT {1186,176}
        POINT {1220,192}
        POINT {1216,221}
      }
    }
  }

  SCALE_LEVEL {
    Y=274
    SCALE=40
  }
  SCALE_LEVEL {
    Y=768
    SCALE=70
  }

  ; ----- free entities
  ENTITY {
    NAME="Coffin"
    X=458
    Y=614
    SPRITE="scenes\blackchamber\sprites\coffin.sprite"
  }
}
```

A `.scene` file is a [definition file](definition-files.md) with one
`SCENE` root block. Everything the engine does not know is ignored; the
tables below list the keys it reads, with the defaults it uses when a key
is absent.

## `SCENE`

| Key | Type | Default | Meaning |
|-----|------|---------|---------|
| `NAME` | string | `""` | Name used by scripts. |
| `CAPTION` | string | `""` | Caption shown by the interface. |
| `TEMPLATE` | string | | Another scene file loaded first; this file then overrides it. Not written by the editor. |
| `SCRIPT` | string, repeatable | | Scripts attached to the scene, run in order. |
| `PROPERTY` | block, repeatable | | A script property set on the scene, see [`PROPERTY`](#property). |
| `PERSISTENT_STATE` | bool | false | Remember the state of the scene's named nodes (active, caption, sprite, cursor, alpha colour) when the player leaves, and put it back when they come back; see [game-loop.md](../game-loop.md#scene-state-between-visits). Positions and script variables are not kept. |
| `PERSISTENT_STATE_SPRITES` | bool | true | With `PERSISTENT_STATE`, also keep the sprites objects were switched to. |
| `CURSOR` | string | | Sprite used as the mouse cursor over the scene instead of the game's cursor. |
| `VIEWPORT` | `left,top,right,bottom` | the whole window | Part of the window the scene is drawn in. Not written by the editor. |
| `CAMERA` | string | | Name of the active 3D camera in the scene geometry. Only meaningful for the 3D version of the engine; a 2D scene never has one. |
| `LAYER` | block, repeatable | | The layers, drawn in order, see [`LAYER`](#layer). |
| `ENTITY` | block, repeatable | | *Free* entities, see [Free entities](#free-entities). |
| `WAYPOINTS` | block, repeatable | | Waypoint groups, see [`WAYPOINTS`](#waypoints). |
| `SCALE_LEVEL` | block, repeatable | | See [Scale and rotation levels](#scale-and-rotation-levels). |
| `ROTATION_LEVEL` | block, repeatable | | Same. |
| `EDITOR_MARGIN_H`, `EDITOR_MARGIN_V`, `EDITOR_COLOR_*`, `EDITOR_SHOW_*`, `EDITOR_PROPERTY` | | | Editor state, ignored by the engine. |
| `EVENTS` | | | Reserved, ignored. |

A scene with no main layer loads, with a warning, and has a size of
`0,0`.

## `LAYER`

| Key | Type | Default | Meaning |
|-----|------|---------|---------|
| `NAME` | string | `""` | Name used by scripts. |
| `CAPTION` | string | `""` | |
| `MAIN` | bool | false | The main layer. The scene takes its `WIDTH` and `HEIGHT`, its regions define the floor, and actors are drawn inside it. The last layer with `MAIN=TRUE` wins. |
| `WIDTH`, `HEIGHT` | int | 0 | Size of the layer in pixels. Layers larger than the main one scroll faster, smaller ones slower (parallax). |
| `ACTIVE` | bool | true | An inactive layer is neither drawn nor updated. |
| `CLOSE_UP` | bool | false | The layer is a close-up: a full-screen shield is drawn under it that swallows mouse clicks meant for the layers below. |
| `ENTITY` | block, repeatable | | An entity node, see [`ENTITY`](#entity). |
| `REGION` | block, repeatable | | A region node, see [`REGION`](#region). |
| `SCRIPT` | string, repeatable | | Scripts attached to the layer. |
| `PROPERTY` | block, repeatable | | Script properties. |
| `TEMPLATE` | string | | Another layer file loaded first. |
| `EDITOR_SELECTED`, `EDITOR_PROPERTY` | | | Editor state, ignored. |

The entities and regions of a layer form one ordered list of **nodes**;
the order in the file is the drawing order (first node at the back) and
the order scripts see (`Layer.GetNode(i)`).

An entity in a layer is **not scalable by default**, unlike an entity
loaded from an `.entity` file: the loader clears `SCALABLE` before reading
the block, so only an explicit `SCALABLE=TRUE` makes it follow the scale
levels.

## `ENTITY`

The same block describes an entity inside a layer, a free entity of the
scene and the root block of an `.entity` file.

| Key | Type | Default | Meaning |
|-----|------|---------|---------|
| `NAME` | string | `""` | Name used by scripts. |
| `CAPTION` | string | `""` | Caption shown by the interface when the mouse is over the entity. Often a string-table reference (`/STORER0002/Console`). |
| `ACTIVE` | bool | true | An inactive entity is neither drawn, updated nor clickable. |
| `X`, `Y` | int | 0 | Position: the sprite's hotspot is placed here, and the position is used for depth sorting, scale and tint lookups. |
| `SPRITE` | string | | Sprite (or image) drawn at the position. An entity may have no sprite and only a `REGION` (an invisible hotspot). |
| `SCALABLE` | bool | true (`.entity`) / false (in a layer) | Scale the sprite according to the scene's scale levels and regions, see [Scale at a point](#scale-at-a-point). |
| `SCALE` | int | none | Fixed scale in percent, overriding the scene's. |
| `RELATIVE_SCALE` | int | 0 | Added to the scene's scale, in percent. |
| `ROTATABLE` (or `ROTABLE`) | bool | false | Rotate the sprite according to the rotation levels. |
| `INTERACTIVE` (or `REGISTRABLE`) | bool | true | The entity reacts to the mouse (hover, click). |
| `COLORABLE` (or `SHADOWABLE`) | bool | true | The entity takes the tint of the region it stands in, see [Tint at a point](#tint-at-a-point). |
| `ALPHA_COLOR` | `r,g,b` | none | Fixed tint, overriding the scene's. |
| `ALPHA` | int 0–255 | none | Fixed opacity. `ALPHA` without `ALPHA_COLOR` means `255,255,255` with that alpha. |
| `CURSOR` | string | | Sprite used as the mouse cursor over the entity. |
| `REGION` | block | | Clickable area as a polygon, see [`REGION`](#region); only the base keys are read. Without it, the sprite's pixels are the clickable area. |
| `BLOCKED_REGION` | block | | Polygon that blocks actors while the entity is there (a crate on the floor). |
| `WAYPOINTS` | block | | Waypoints that become available while the entity is there (a ladder). |
| `WALK_TO_X`, `WALK_TO_Y` | int | 0 | Where the actor walks before interacting with the entity. |
| `WALK_TO_DIR` | int | none | Direction the actor turns to when it arrives: `0` up, `1` up-right, `2` right, `3` down-right, `4` down, `5` down-left, `6` left, `7` up-left. Negative values mean `0`, values of `8` and above mean none. |
| `SCRIPT` | string, repeatable | | Scripts attached to the entity. |
| `PROPERTY` | block, repeatable | | Script properties. |
| `ITEM` | string | | Name of the inventory item this entity represents; the entity is made inactive once the item has been taken. |
| `IGNORE_ITEMS` | bool | false | The entity is not clickable while an inventory item is selected. |
| `SAVE_STATE` | bool | true | Include the entity in the scene's persistent state. |
| `FONT` | string | | Font used for the entity's speech. |
| `TALK` | string, repeatable | | Sprites played while the entity talks. |
| `TALK_SPECIAL` | string, repeatable | | Alternative talk sprites, chosen by the script. |
| `SUBTYPE` | string | normal | `"sound"` makes a sound source instead of a visible entity: no sprite, not clickable, not scalable. |
| `SOUND` | string | | Sound started when the entity loads (a sound entity's sound, or an ambience). |
| `SOUND_START_TIME` | int | 0 | Start offset of the sound, in milliseconds. |
| `SOUND_VOLUME` | int | 100 | Volume of the sound in percent. |
| `SOUND_PANNING` | bool | true | Pan the sound according to the entity's position on screen. |
| `TEMPLATE` | string | | Another entity file loaded first. |
| `EDITOR_SELECTED`, `EDITOR_PROPERTY` | | | Editor state, ignored. |
| `EVENTS` | | | Reserved, ignored. |

An entity with both a `SPRITE` and a `REGION` loads with a warning: the
region is then the clickable area and the sprite's pixels are not. Its
points are scene coordinates, placed on screen with the offset of the
layer the entity is drawn in, like the sprite; a scene smaller than its
viewport keeps a negative scroll offset but draws its layers at the
viewport's origin, and its hotspots are where its layers are drawn.

## `REGION`

A region is a polygon given by its `POINT`s in order; the last point is
joined to the first. A region in a layer carries the extra keys marked
*scene*; the `REGION` of an entity reads only the base keys.

| Key | Type | Default | Meaning |
|-----|------|---------|---------|
| `NAME` | string | `""` | Name used by scripts. `<unnamed>` is what the editor writes for a nameless one. |
| `CAPTION` | string | `""` | |
| `ACTIVE` | bool | true | An inactive region does not block, scale, tint or contain anything. |
| `POINT` | `x,y`, repeatable | | The vertices. A polygon needs at least three; fewer contain no point. |
| `SCRIPT` | string, repeatable | | Scripts attached to the region (it receives mouse events like an entity). |
| `PROPERTY` | block, repeatable | | Script properties. |
| `BLOCKED` | bool | false | *scene.* Actors cannot walk into it. |
| `DECORATION` | bool | false | *scene.* The region only exists for scripts (as a trigger area); objects inside it are not sorted into it when drawing. |
| `SCALE` (or `ZOOM`) | int | 0 | *scene.* Scale in percent applied to whoever stands inside; `0` means "use the scale levels". |
| `ALPHA_COLOR` | `r,g,b` | `255,255,255` | *scene.* Tint applied to whoever stands inside (with `COLORABLE`). |
| `ALPHA` | int 0–255 | 255 | *scene.* Opacity applied the same way. |
| `TEMPLATE` | string | | Another region file loaded first. |
| `EDITOR_SELECTED`, `EDITOR_SELECTED_POINT`, `EDITOR_PROPERTY` | | | Editor state, ignored. |

### Point in region

A point is inside a region when it is inside the polygon's bounding
rectangle (right and bottom exclusive) and an even-odd test on the edges
succeeds: cast a ray to the left, count the edges it crosses, odd means
inside. Edges are compared with `>` on the lower end and `<=` on the upper
end of their vertical span, so a point exactly on a horizontal edge is
counted consistently.

## `WAYPOINTS`

| Key | Type | Default | Meaning |
|-----|------|---------|---------|
| `NAME` | string | `""` | Name used by scripts. |
| `POINT` | `x,y`, repeatable | | The waypoints. |
| `PROPERTY` | block, repeatable | | Script properties. |
| `TEMPLATE` | string | | Another file loaded first. |
| `EDITOR_SELECTED`, `EDITOR_SELECTED_POINT`, `EDITOR_PROPERTY` | | | Editor state, ignored. |

Waypoints are the vertices of the path-finding graph. An actor walks in a
straight line when nothing blocks the way; otherwise the engine looks for
a path from the actor to the target through waypoints that see each other
(a straight line between them crosses no blocked region and leaves no
walkable one).

## `PROPERTY`

```
PROPERTY {
  NAME="xSurface"
  VALUE="metalecho"
}
```

Sets the script property `NAME` of the object to the string `VALUE`.
Both keys are required; a block missing one fails to load. Scripts read
it as `this.xSurface`.

`EDITOR_PROPERTY` has the same shape and is ignored outside the editors.

## Scale and rotation levels

```
SCALE_LEVEL {
  Y=274
  SCALE=40
}
ROTATION_LEVEL {
  X=100
  ROTATION=-10
}
```

| Block | Keys | Defaults |
|-------|------|----------|
| `SCALE_LEVEL` | `Y` int, `SCALE` int (percent) | `0`, `100` |
| `ROTATION_LEVEL` | `X` int, `ROTATION` int (degrees) | `0`, `0` |

After loading, scale levels are sorted by `Y` and rotation levels by `X`.

**Scale at a `Y`**: take the last level with `Y` strictly below the
position (`prev`) and the first level with `Y` greater or equal (`next`).
If either is missing the scale is `100`. Otherwise it is interpolated linearly between `prev` and
`next`. With the two levels above, an actor at `Y=521` is drawn at 55 %.

**Rotation at an `X`**: the same rule on `X`, with `0` when outside the
levels.

### Scale at a point

The scale of a scalable object at `(x, y)` is:

1. the `SCALE` of the **last** active, non-blocked region of the main
   layer that contains the point and has a non-zero `SCALE`;
2. otherwise the scale level interpolation at `y`.

An entity then uses, in order: its own `SCALE` if set, else the scale at
its position plus its `RELATIVE_SCALE`. A non-scalable entity is drawn at
100 %.

### Tint at a point

The tint of a colorable object at `(x, y)` is the `ALPHA_COLOR` and
`ALPHA` of the **last** active, non-blocked region of the main layer that
contains the point, else opaque white. An entity with its own
`ALPHA_COLOR` or `ALPHA` ignores the regions; a non-colorable one is drawn
untinted.

### Blocked at a point

Walk the main layer's active, non-`DECORATION` regions in order, keeping
those that contain the point: the **first** `BLOCKED` one makes the point
blocked; otherwise the point is free if at least one walkable region
contains it, and blocked when none does (off the floor). The
`BLOCKED_REGION`s of active entities and actors block as well. Actors may
only walk on unblocked points.

## Free entities

`ENTITY` blocks directly under `SCENE` are *free* entities: they are not
nodes of a layer but belong to the scene's object list, like actors. The
editor writes them after the layers under a `; ----- free entities`
comment. Unlike layer entities they are scalable by default.

## Drawing

For each active layer, in order:

1. Compute the layer's scroll offset (see [Camera](#camera)).
2. Walk the layer's nodes in order. An active entity node is drawn at its
   position. A region node that is neither `BLOCKED` nor `DECORATION`
   draws the **free objects** (actors and free entities) whose position is
   inside it and that have not been drawn yet, sorted by `Y`, so that an
   actor standing on the floor region is drawn between the background
   (before the region in the file) and the foreground props (after it).
3. After the nodes of the **main** layer, draw the remaining free objects
   (those inside no region), sorted by `Y`.

Entities with `SUBTYPE="sound"` are never drawn. A `CLOSE_UP` layer first
draws a full-screen shield that captures the mouse.

## Camera

The 2D engine has no camera object: the scene is drawn through a
**viewport** (the window, or `VIEWPORT` when set) and a **scroll offset**
`(offset_x, offset_y)` clamped to `[0, scene_width - viewport_width]` and
`[0, scene_height - viewport_height]`. The scroll follows the main actor
("auto scroll": one pixel every 10 ms by default, both configurable by
scripts) or is set by scripts.

Each layer is scrolled proportionally to its own size (parallax):

```
ratio_x  = offset_x / (scene_width  - viewport_width)      (0 when not scrollable)
layer_x  = ratio_x  * (layer_width  - viewport_width)
```

and the same for `y`. A layer the size of the main layer scrolls with it;
a wider layer scrolls faster (foreground), a narrower one slower
(background). The main layer, by definition, scrolls by exactly
`offset_x`. Parallax can be switched off by scripts, in which case every
layer scrolls by the scene offset.

`CAMERA` names a camera of the 3D geometry in the 3D version of the
engine, which sets up a perspective view for 3D actors from it; the 2D
engine reads and ignores the key.

## Notes for implementers

- Keep the node order of each layer: it is the drawing order and the index
  scripts use.
- Scene entities default to `SCALABLE=FALSE`, `.entity` files and free
  entities to `TRUE`; the editor writes the key every time, but hand-made
  files may rely on the default.
- `TEMPLATE` needs the file system; a parser working on bytes should
  record the name and let the caller load and merge it.
- Sprite, cursor and script paths are relative to the game root with `\`
  separators; resolve them through the virtual file system.
- A missing sprite is not fatal for the engine (the entity draws nothing);
  report it and keep the scene.
